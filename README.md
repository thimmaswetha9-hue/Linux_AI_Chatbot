# 🐧 Linux AI Chatbot

An intelligent, full-stack AI-powered Linux assistant designed for students, DevOps engineers, and Linux beginners. Built with modern UI/UX design, real-time command assistance, and Gemini AI integration.

---

### 🌐 Live Demo

* **Web Application:** [https://linux-ai-chatbot.onrender.com](https://linux-ai-chatbot.onrender.com)
* **GitHub Pages:** [https://thimmaswetha9-hue.github.io/Linux_AI_Chatbot/](https://thimmaswetha9-hue.github.io/Linux_AI_Chatbot/)

---

### ✨ Key Features

* **Smart Linux Assistant:** Instant explanations for terminal commands, script troubleshooting, and Linux internals powered by Google Gemini.
* **Built-in Local Knowledge:** Instant responses for beginner commands, file permissions (`chmod`), diagnostics (`top`, `free`), and package management without API delays.
* **Destructive Command Warnings:** Safety warnings and guidelines for irreversible operations (like `rm -rf`).
* **Clean Terminal UI:** Modern web terminal aesthetic with styled markdown code blocks for easy copy-pasting.

---

### 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, Modern JavaScript
* **Backend:** Python 3, Flask, Flask-CORS, Gunicorn
* **AI Model:** Google Gemini API (`gemini-2.5-flash`)
* **Deployment:** Render (Backend API), GitHub Pages
